ВАЖНО: ИНСТРУКЦИЯ ПО НАСТРОЙКЕ GOOGLE CLOUD TTS
=================================================

Для работы озвучки (TTS) требуется сервисный ключ Google Cloud.
Сам ключ (файл .json) НЕЛЬЗЯ загружать в репозиторий (он в .gitignore).

ШАГ 1. Получение ключа
----------------------
1. Зайдите в Google Cloud Console: https://console.cloud.google.com/
2. Создайте новый проект (или выберите существующий).
3. В поиске найдите "Cloud Text-to-Speech API" и нажмите "Enable" (Включить).
   !!! ВНИМАНИЕ: Для этого потребуется привязать карту (Billing Account).
   !!! Google даёт бесплатные лимиты, но если их превысить — будут списываться деньги.
   !!! Следите за биллингом в консоли!

4. Перейдите в "IAM & Admin" -> "Service Accounts" (Сервисные аккаунты).
5. Нажмите "Create Service Account".
   - Имя: любое (например, deck-builder-tts).
   - Роль: Project -> Viewer (или Cloud TTS Admin).
6. Нажмите на созданный аккаунт, вкладка "Keys" (Ключи) -> "Add Key" -> "Create new key".
7. Выберите формат JSON.
8. Файл скачается на компьютер.

ШАГ 2. Установка ключа
----------------------
1. Переименуйте скачанный файл в: ВАШЕ_НАЗВАНИЕ_ФАЙЛА_С_КЛЮЧОМ.json
2. Положите его в эту папку: tools/deck_builder/keys/
   (Путь должен быть: .../keys/ВАШЕ_НАЗВАНИЕ_ФАЙЛА_С_КЛЮЧОМ.json)

ШАГ 3. Настройка ID проекта
---------------------------
1. Откройте файл конфига: tools/deck_builder/config.py
2. Найдите переменную: PROJECT_ID = "..." (Название проекта можно найти в самом файле ключа в переменной "project_id")
3. Впишите туда ID вашего проекта из Google Cloud Console (не название, а именно ID, обычно с цифрами).
4. Найдите строку и пропишите название ключа: "GOOGLE_CREDENTIALS", os.path.join(BASE_DIR, "keys/ВАШЕ_НАЗВАНИЕ_ФАЙЛА_С_КЛЮЧОМ.json"))
