# Anki Card Creator
Приложение для создания карточек Anki с текстом, аудио и видео.

## Установка
1. Установите Python 3.8+.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Настройте Google TTS (см. config.py).

## Использование
1. Поместите файлы в `input/`.
2. Запустите `main.py`.
